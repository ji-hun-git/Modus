# Authored record-brief example

These four CSV documents and all their entries are fictional, authored for Modus development on 28 October 2026. They describe no real person, are not Synthea output and are not medical advice. They are public demonstration inputs, not held-out evaluation material.

Import and review files 01–03 first. A brief can include a childhood vaccination with only a recorded year, a visit, a provider-recorded assessment, a past prescription, a procedure, report text and measurements. The source date of the undated childhood note stays unknown. The prescription does not establish present medication use.

Import file 04 later to demonstrate a second Ferritin value for the same recorded date. Its later availability is stamped by the actual review/commit operation, not backdated from this filename or note. Neither 32.0 nor 29.5 is automatically selected as correct. Selecting either conflicting fact for a brief must reveal both values and sources before export.

The example tests record organization, provenance, human selection and temporal integrity. No diagnostic accuracy, biological realism, clinical usefulness or user time saving is established by this fixture. Record collection from actual institutions remains outside this example.
