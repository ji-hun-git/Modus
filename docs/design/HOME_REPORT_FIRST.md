# Home: the report before the machinery

Apply Anthropic frontend-design and Vercel web-design-guidelines to the existing orbit product, not a new template. Skills were installed from their first-party repositories on 2 November 2026. Installation is not quality evidence; actual browser checks decide acceptance.

Direction: a personal record desk. The selected report owns the reading order; the orbit remains the memorable file navigator. Keep the black/white palette and self-hosted Inter. Use existing void, surface, line, muted and star tokens; no new accent color or font dependency. Left-align report headings and values; use tabular numbers. Relax tracked capitals in the task content, retain them only in existing brand/navigation chrome.

Desktop: report title and up to four visible reading choices on the left, compact owner/file orbit on the right. The selected reading shows its dated history immediately below. One Ask bar and the existing time controls finish the page. Mobile: report first, history second, compact orbit next; no clipped horizontal content or nested report scrollbar.

Before: orbit → dropdown → hidden earlier-results accordion → inspect source.
After: report → visible readings → dated history → click any reading/point for original evidence.

No health score, colored clinical judgment, invented trend narrative, automatic conflict winner or decorative metrics. If units differ, keep separate chart scales. No numeric delta is computed in the browser. Partial dates and source availability stay explicit. Limit report choices and history rendering, and offer the rest through existing pages.

Acceptance: switch files and readings without stale evidence, open historical sources, ask from Home under the same captured scope, use keyboard controls, inspect at mobile width, and pass offline service regression. Preserve evaluation/held-out artifacts and spend no model credits.
